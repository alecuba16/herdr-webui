## Resolution

- MEDIUM: the first tm7 draft named its mint result `mint`, colliding with tm4's local of the same name. Node refused to load the driver (SyntaxError) before any browser run. Renamed to `reMint`.
- MEDIUM: the tm7 wsIdNow eval under-escaped its regex: `\/` in the template literal shipped to the browser as `/workspace/` (empty regex) followed by `([^/]+)/)`, so the eval threw `Unexpected token '^'` and the driver crashed between tm7a and tm7b. Fixed to `\\/`; the clean rerun then passed 21/21.
- The first tm7 draft also carried a dead wait loop (an always-true `wsGone` expression polling DOM state). Removed before any run shipped it: the real assertion is the single server-side /api/workspaces poll.
- One earlier run failed tm5 with a stale panels chip while the server had zero tabs; it coincided with broken-pipe server errors and a Jcode session server reload interrupting a parallel run. Identical code passed tm5 in the next two runs (seeded option off, chip "0 panes", server alive), so environment noise, not shipped-code.

No shipped-code findings. The mobile "Close workspace with last terminal" row copy passes: specific, states the default, states what turning it off does.
