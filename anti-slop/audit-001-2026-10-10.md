# Antislop audit 001, 2026-10-10

Review scope: desktop workspace pane, right-sidebar search, file-browser navigation, and shared search content controls on branch `update_windows`.

Dial read: desktop developer tool UI, calm and utility-first, ENERGY 1 / RHYTHM 1 / MOTION 1. Existing design direction is defined by `docs/ux/design-system.md`. Findings below are functional hard-gate defects, not aesthetic preferences.

1. **HIGH, R-26 / C-2:** Embedded Search result rows render `chooseSearchResult(...)` and recent-row removal through the palette API, while the panel owns separate state. Panel rendering also never populates its `results` list. Workspace, action, and recent controls therefore resolve against stale palette state or no result and are dead or misrouted.
2. **HIGH, R-26 / C-4:** Selecting a file or folder from the embedded Search panel calls `HerdrFileBrowser.openAt`, but that entry point does not move the file-browser panel into the right-sidebar host. The shell mode changes to Files while the Search panel can remain visible, so the active rail and content disagree.
3. **HIGH, R-26 / C-2:** Shared content-search markup exposes `Load all matches` when a file is truncated, but both desktop palette and embedded-panel callbacks implement `loadFile` as an empty function. The visible control has no behavior.
4. **MEDIUM, R-27 / C-4:** Search panel open/close navigation is not covered for the cross-surface transitions above. Existing tests assert markup and hosting, but not that a rendered result click selects the panel-owned result or that file navigation replaces the hosted search surface.

## Resolution

- Finding 1: panel rows now use panel-owned result indexes and callbacks.
- Finding 2: file-browser `openAt` now claims the Files sidebar host and closes Search first.
- Finding 3: both desktop search surfaces now load full matches through the shared per-file endpoint.
- Finding 4: regression tests cover panel selection, per-file expansion, endpoint construction, and Search-to-Files hosting.
- Follow-up: the desktop keyboard audit now opens Find through the pane strip control, and the full mobile plus desktop live audit passes.
