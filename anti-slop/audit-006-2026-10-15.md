## Design Read

Reading this as: a mobile terminal utility for users sending agent messages and entering terminal control input, using the existing dense terminal visual language. Dials: ENERGY 1 / RHYTHM 1 / MOTION 1. The terminal remains the focal surface, the composer is a compact utility row below it, and the key bar keeps its existing control-key pattern. Direction comes from `docs/ux/design-system.md`, `docs/ux/backlog-features-design.md`, the existing mobile shell, and the user request.
